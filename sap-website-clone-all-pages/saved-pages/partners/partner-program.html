A program to grow your business

The SAP PartnerEdge program offers four simple engagement models: Build, Sell, Service, and Run.

  • Sell partners

    With this track, resellers and value-added resellers can own the entire customer lifecycle or collaborate with other partners or SAP.

    Learn about the Sell track

  • Build partners

    This model is ideal for original equipment manufacturers, independent software vendors, and application developers that build solutions on top of, or to integrate with, SAP technology.

    Learn about the Build track

  • Service partners

    Service partners help consultants or systems integrators provide strategic consulting, system design, solution integration, and implementation of SAP solutions.

    Learn about the Service track

  • Run partners

    As a managed service provider or outsourcing partner, you can offer your customers SAP solutions as part of an anything-as-a-service model through one bundled subscription.

    Learn about the Run track
