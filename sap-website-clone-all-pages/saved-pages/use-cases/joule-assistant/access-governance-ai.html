Overview

The Access Governance and Security Assistant combines access governance and security across every identity in SAP: human, nonhuman, and AI agents. It prevents risky access, keeps systems secure, detects threats, and delivers forensic visibility into who or what performed each action—moving teams from point-in-time audits to continuous, provable oversight.

Tasks this assistant can help with:
  • Simulating role and authorization change impact
  • Detecting and explaining segregation-of-duties conflicts
  • Automating access certification and Firefighter reviews
  • Auto-generating alert-specific response playbooks
  • Aggregating related security alerts
  • Documenting user activity via AI log analysis
  • Scoring and summarizing investigations by stakeholder
  • Monitoring nonhuman and AI agent access for anomalies
Example use cases for this assistant:
  • Compliant role cleanup during migration to SAP S/4HANA
  • Time-boxed, audit-ready emergency access
  • Security weaknesses surfaced before exploitation
  • Unrelated alerts correlated into one investigation
  • Insider and privilege abuse detected through behavior analysis
  • Runtime monitoring and attribution of Joule Agent and other AI agent actions
  • Continuous audit evidence for NIS2, DORA, SOX, and the EU AI Act

Agents used by this assistant

Use the Access Governance and Security Assistant to orchestrate specialized AI agents, including Joule Agents that apply SAP's access and security expertise, or custom agents you create.

Agent

Description

Access Certification Agent

Analyzes access risks and segregation of duties (SoD) violations to automate certification reviews and remediation.

Firefighter Log Review Agent

Reviews emergency-access sessions automatically, keeping privileged activity logged and audit-ready.

Security Threat Processing Agent

Aggregates alerts, analyzes human and non-human behavior, scores severity, and generates playbooks.

User Access Review Agent

Flags high-risk access outliers for targeted access reviews.

User Authorization Request Agent

Converts plain-language access needs into a least-privilege, SoD-checked request.
