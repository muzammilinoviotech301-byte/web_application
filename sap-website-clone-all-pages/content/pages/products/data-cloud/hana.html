What is SAP HANA Cloud?

As the AI database for SAP Business Data Cloud, SAP HANA Cloud gives you a single multi-model engine to amplify agents and applications across all your data.

Bring the engine powering SAP Business Data Cloud’s business data fabric to your AI foundation.

  • Combine relational, graph, vector, spatial, and JSON data from a single engine.

  • Unify data models, preserving business semantics and running AI directly over all your data.

  • Scale compute and storage independently as demands shift.

  • Build across Joule Studio, SAP Business Application Studio, and third-party IDEs – all connected to governed data.

Key features

Store and query multi-model data

Store, process, and query multi-model data in a single in-memory database, eliminating the need for separate transactional, analytical, and multi-model systems that introduce latency and disrupt conversational and agentic workflows.

Run native AI and semantic processing

Run vector search, knowledge graph queries, and machine learning directly inside the database, executing generative and predictive AI on live enterprise data using SQL-based functions, including support for persistent agent memory.

Predict outcomes from structured data

SAP-RPT-1 is a relational pretrained transformer model that delivers instant classification and regression predictions from structured business data at runtime, with no model training or machine learning expertise required.

Develop faster with unified, governed tools

Build context-aware applications and agents across no-code to pro-code environments, connected to governed data and SAP's business knowledge layer, with reusable data products that eliminate redundant data preparation.

Scale elastically with optimized performance

Scale compute and storage elastically with intelligent data tiering and native workload management to keep inference fast, costs predictable, and TCO low without added infrastructure complexity.

Frequently asked questions

SAP HANA Cloud is a multi-model AI database that processes relational, graph, vector, spatial, JSON, and time-series data in a single engine, grounding every agent and application in trusted, real-time business context. With native knowledge graph and business semantics built in, SAP HANA Cloud preserves meaning and relationships across data models, enabling AI agents and applications to reason across enterprise data.

SAP HANA Cloud provides the data foundation AI agents and applications need to reason across structured and unstructured data. With native knowledge graph, vector processing, and semantic capabilities, it enables context-aware applications that go beyond traditional database functions.

SAP HANA Cloud is the trusted database foundation that powers strategic solutions like SAP Business Data Cloud, enabling your data to drive innovation and insight. It can also consume curated data products from SAP Business Data Cloud.

SAP HANA Cloud supports access to both SAP and third-party data management practices, including federation and replication methods. It uses smart data access (SDA) and smart data integration (SDI), and access includes ODBC, REST, JDBC, and the data provisioning agent (DPAgent), and JDBC.
