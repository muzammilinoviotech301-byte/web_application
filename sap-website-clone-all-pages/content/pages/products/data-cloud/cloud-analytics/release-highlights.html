Featured highlights

Data entry: repost data

Save time in planning with data reposting in SAP Analytics Cloud. Change dimension values on booked member combinations to repost data to unbooked target member combinations directly in your table, without leaving your planning context.

Data entry: insertion of multiple new lines

Streamline planning data entry by adding one or five member combinations at once. Paste content from the clipboard, use automatic validation to identify invalid entries, including master data, and correct highlighted values before submitting updates for processing.

Advanced formulas: string manipulation functions

Simplify planning models with string functions in SAP Analytics Cloud advanced formulas. Merge strings with CONCAT, select starting or ending characters with LEFT and RIGHT, and extract substrings with SUBSTR to reduce dependencies and make models easier to understand.

Filter: two new ways to filter tables

Focus your analysis with two new table filters. Apply conditions such as greater than, less than, or equal to a threshold directly in the widget, without model changes. Filter from row or column headers without opening the builder panel.

Sorting in waterfall charts

Explore waterfall charts with sorting in the quick action menu: ascending, descending, custom, highest-to-lowest, or lowest-to-highest. Sort by variance value in variance mode to surface key differences. Waterfall charts also support linked analysis as both sources and targets for cross-widget interactions.
