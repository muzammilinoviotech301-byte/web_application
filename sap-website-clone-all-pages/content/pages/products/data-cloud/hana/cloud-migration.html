Frequently asked questions

The SAP HANA Cloud database offers the same power and performance of the SAP HANA database. However, SAP HANA Cloud is a database as a service built natively for the cloud, offering greater connectivity and flexibility, plus several new features.

 

With SAP HANA Cloud, SAP manages hardware, operating systems, backups, and other types of maintenance.

A cloud database provides faster access to data, is a scalable, fully managed solution that reduces maintenance, and its pricing is based on consumption.

You can choose from a range of migration automation tools, accelerators, and services to streamline the complete migration journey—from initial planning to go-live—to achieve a faster path to innovation, productivity, and adoption.

You can migrate or extend on-premises database landscapes to the cloud with expanded capacity for innovation, computing, and storage to begin your cloud journey.
