SAP ASE, our relational database server

SAP ASE is our high performance transactional relational database. Drive faster, more reliable online transaction processing (OLTP) for less with SAP ASE. SAP ASE is our transactional database within the SAP Business Technology Platform portfolio.

  • Deploy as a cloud infrastructure as a service, as a fully managed cloud database as a service, or on premises

  • Designed to scale for intense and high-performance workloads

  • Securely and reliably capture your transactional data

  • Proven flexible SQL database system to reduce risk and increase agility

  • Lower operational costs with a resource-efficient relational database server

Key benefits

Improved performance for transaction processing

  • Highly scalable database engine

  • Designed for intense transactional workloads

  • Designed for modern era of virtualization and high core CPUs

  • In memory capabilities to push concurrency even higher

 

Business continuity and data security

  • All communication can be encrypted with SSL

  • Provides individual column encryption or full database encryption

  • Fine grained security controls

  • Full auditing with granular control

  • Extend authentication to external sources (AD/LDAP/Kerberos)

  • Ability to configure a 2-3 node HA/DR setup with always-on option

Multiple deployment options

Optimize your workloads and deploy in a public cloud infrastructure as a service; in SAP ASE, cloud edition by IBM Cloud; or on premises

SAP ASE Features

Increase performance and accelerate transactional processing with enhanced technology innovations.

XOLTP

  • Improve transaction processing efficiency

  • Support a high-performance, low-latency XOLTP engine

  • Enable application compatibility for snapshot isolation

  • Apply capabilities of modern multicore computing platforms

  • Accelerate query execution with higher concurrency and lower contention

Encryption

  • Protect your business data from unplanned downtime and breaches

  • Support granular, native data encryption

  • Keep your service levels consistent by securing your data

Administration and Management Console

  • Graphical user interface for managing ASE

  • Integrated with always-on and workload analyzer

  • Visually assess the status of your server

Partitions

  • Divide large data volumes into smaller pieces across your RDBMS

  • Enable users to access and analyze specific data groups for faster insights

  • Accelerate transaction processing by turning massive volumes of data into easy-to-consume data groups

Always-On

  • Configure a HA pair of ASEs

  • Configure a HA/DR pair of ASEs

  • Protect your data with a zero data loss solution

Workload analyzer

  • Optimize performance through workload analysis

  • Capture, analyze, and replay production workloads

  • Assess the impact of configuration changes on application performance quickly, without disruption

  • Refine applications based on real-life workload diagnostics

  • Optimize ASE configuration settings with structured testing approach

  • Access from command line or AMC
