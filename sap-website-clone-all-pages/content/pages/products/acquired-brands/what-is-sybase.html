What is Sybase?

Sybase, Inc. was an enterprise software and services company, that produced software relating to relational databases. The company was acquired by SAP in 2010.

What is Sybase?

Sybase, Inc. was an enterprise software and services company, acquired by SAP in 2010 to accelerate the reach of SAP solutions across mobile platforms and help companies manage and analyze business information and processes on any device. By combining the strength of in-memory technology with Sybase solutions, SAP offers the most robust data platform to achieve business agility.

Sybase solutions are a strategic part of SAP’s data management portfolio.

Sybase Adaptive Server Enterprise (ASE)

Sybase ASE was renamed to SAP ASE. A high-performance SQL database server that uses a relational management model to meet rising demand for performance, reliability, and efficiency in every industry.

Explore SAP Adaptive Server Enterprise 

Sybase IQ

Sybase IQ was renamed SAP IQ. A columnar analytics database that delivers high-performance decision-support for mission-critical business intelligence, analytics, and data warehousing. SAP IQ is a column-based in-disk relational database with a low-cost environment.

Explore SAP IQ 

Sybase SQL Anywhere

Sybase SQL Anywhere was renamed to SAP SQL Anywhere. An embedded database that enables secure, reliable data management for servers where no DBA is available and synchronization for tens of thousands of mobile devices, Internet of Things (IoT) systems, and remote environments.

Explore SAP SQL Anywhere 

Sybase Replication Server

Sybase Replication Server was renamed to SAP Replication Server. A data replication software for real-time data updates from anywhere in the enterprise. Deliver seamless data management, integration, and synchronization from SAP and non-SAP data to satisfy mission-critical tasks.

Explore SAP Replication Server 

Sybase PowerDesigner

Sybase PowerDesigner was renamed to SAP PowerDesigner. A data modeling tool View change impact with a blueprint of current enterprise architectures. Automatically capture architecture layers, tap into a powerful metadata repository, and easily share information.

Explore SAP PowerDesigner
