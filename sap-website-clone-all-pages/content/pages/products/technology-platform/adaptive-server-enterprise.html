What is SAP Adaptive Server Enterprise, cloud edition by IBM Cloud?

The cloud edition of SAP ASE is a database as a service that offers managed services, cloud resiliency, and security and compliance standards from IBM Cloud.

Mission-critical transactions on a high-availability cloud architecture

  • Benefit from cloud infrastructure and database administration as a managed service​

  • Maintain business continuity with 99.9% uptime service level agreement​

  • Securely and easily migrate your data to the cloud

  • Grow at your own pace with a consumption-based subscription

Frequently asked questions

The top benefits of cloud databases are faster access to data, consumption-based pricing, and using a fully managed solution to reduce capital expenditures and maintenance costs.

SAP ASE is an on-premises solution. SAP ASE, cloud edition by IBM Cloud is a managed service offering of SAP ASE with near-complete parity. Differences are limited to the inclusion of cloud-specific security capabilities, a new self-service cloud portal, and the removal of some deprecated features. In addition, the SAP ASE always-on option is enabled by default for high availability instances.

SAP ASE, cloud edition by IBM Cloud is an SAP solution with managed services provided by IBM Cloud. SAP continues to be your first line of support.

Data migration is managed through encrypted backup and restore, facilitated by a self-service cloud portal.

It is licensed by subscription, using the metric capacity units. The number of capacity units required is based on which of the service options you require. You can work with SAP to determine the correct number of capacity units, allowing you to ramp up or ramp down services as required.
