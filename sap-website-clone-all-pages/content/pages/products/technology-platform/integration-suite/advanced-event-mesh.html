Frequently asked questions

Situational awareness is the ability for people and systems to understand the current state of business data, react quickly, and adapt processes as necessary.

An EDA is a software design pattern where software components within the system communicate with each other through events, which are messages indicating that a specific action has occurred or a particular state has changed.

An event broker is an intermediary component that facilitates communication between applications that produce event messages and applications that consume or listen to the events.

The key to an integration platform-as-a-service (iPaaS) is getting integration technologies to work together. Cloud integration supports mapping and transformation capabilities to make sure source data is converted correctly to the target data structures. API management enables secure access to APIs that are often used with transaction processing. An event mesh works best when combined with other iPaaS capabilities to orchestrate communications.
