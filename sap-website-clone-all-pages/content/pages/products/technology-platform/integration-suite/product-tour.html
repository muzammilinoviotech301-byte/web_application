Overview
SAP Integration Suite is an integration platform-as-a-service (iPaaS) that integrates all your applications, processes, events, and data. Accelerate innovation, automate more processes, and realize a faster time to value.
Guided integration practice
Save valuable time and resources with a well-defined integration strategy. SAP Integration Suite offers a guided integration methodology to cultivate an agile integration practice across your organization.
Access your integration strategy with SAP Integration Solution Advisory Methodology framework that is also built directly into the suite. You can adapt the pre-defined concepts and content to meet your needs.
Design your hybrid integration platform. The Integration Assessment capability within the suite offers a questionnaire-based approach to find the most suitable integration technology for specific requirements.
Define integration best practices. Specify development guidelines to safeguard mission-critical business processes. Reuse the available reference architectures at SAP Discovery Center and adapt to your needs.
Enable a practice of empowerment. Introduce governance with the Integration Assessment capability within SAP Integration Suite. Define and capture requirements with the latest SAP recommendations.

API management
Create a unified and harmonized API façade by utilizing your own custom domain to manage APIs and developer ecosystem thereby decoupling the complexity of underlying systems with API consumers and enabling you to seamlessly scale.
Secure your APIs with enterprise grade policy controls. Apply robust authentication and authorization mechanisms based on OAuth and other security standards. Enforce rate limiting and throttling to prevent abuse.
Curate your APIs comprehensively by discovery, documentation, and lifecycle management tools. Empower developers with self-service tools to enhance productivity and streamline API development and usage.
Monitor API usage with rich operational and business insights provided by analytical dashboards. Utilize AI-based anomaly detection to identify irregularities, ensuring optimal performance and security.
Maximize business functions by composing heterogeneous APIs, data graphs, augmenting APIs with mediation techniques across SAP and non-SAP ecosystem thereby boosting productivity and reach of your APIs.

B2B integration
The library of type system supports common B2B standards such as ASC X12, UN/EDIFACT, Tradacom, Odette, cXML, EANCOM, Automotive Edifacts, Automotive Codelists, SAP iDocs, etc.
Message Implementation Guidelines (MIG) specify how information is being exchanged with the partner. Select type system, message and version used by partners. Also, include name, summary and industry classification.
User-friendly interface for creating and managing mappings between different data formats and structures, and support for functions and expressions.
Based on machine-learning, get proposed implementation guidelines for the specific messages exchanged. Guidelines include confidence indicators for each field in the recommendation.
With Trading Partner Management, create and maintain B2B scenarios for each trading partner.
Store data needed from partner profiles, agreements and configurations in partner directory and process B2B transactions with a generic iflow.
Monitor execution of integration artifacts with each partner.
