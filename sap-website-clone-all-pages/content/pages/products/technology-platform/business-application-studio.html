What is SAP Business Application Studio?

SAP Business Application Studio is a cloud-based professional developer tool for building applications and extending SAP solutions.

Key benefits

  • Accelerate your development projects with an industry-leading IDE and flexible high-productivity tools
  • Leverage tight integration with services, technologies, and systems from SAP
  • Innovate on a trusted and open enterprise platform with built-in governance, security, and DevOps

Key features

Development spaces, virtual environments equipped with the runtimes and tools required for specific development scenarios, are at the heart of SAP Business Application Studio.

Professional full-stack development

Get everything you expect and need from a modern IDE:

  • Familiar desktop-like experience

  • Command line syntax highlighting

  • Integrated debugging

  • Integration with Git and other source control systems

Build a business app 

Productivity tools

Accelerate development with visual programming:

  • Straightforward tools to develop data models

  • Ability to generate OData services without code

  • User interface creation

  • Testing with sample data

  • Connection to external data

  • User role management

Native development on SAP HANA

Build and deploy native applications or analytical models on SAP HANA:

  • SAP HANA database explorer

  • Calculation view editor

  • Modeling tools

  • Support for build, deployment, and validation on multitarget applications

Create a calculation view on SAP HANA  

Development with SAP Fiori

Develop SAP Fiori apps for Cloud Foundry and ABAP:

  • Guided development

  • Service and application modelers

  • Generator for SAP Fiori elements

  • Layout editor for SAPUI5
