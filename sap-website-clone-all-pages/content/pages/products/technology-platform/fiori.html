What is SAP Fiori?

SAP Fiori is an award-winning design system for all SAP products that helps you create web and mobile business applications with an exceptional user experience (UX).

With SAP Fiori you can:

  • Create a consumer-grade application experience with predefined UIs that runs on any device.

  • Quickly build and customize apps that are enterprise-ready, adaptive, accessible, simple, and delightful.

  • Easily adapt and extend existing UIs to meet your needs.

Features

Simplified and harmonized UX

SAP Fiori aims to simplify user experience across SAP applications with intuitive, easy-to-use interfaces, using consistent design and interaction patterns.

Role-based design

SAP Fiori provides role-based access to applications, tailored to the specific needs of different user roles, enhancing relevance and efficiency.

Responsive and adaptive

SAP Fiori applications are responsive, adapting seamlessly to desktops, tablets, and smartphones for a consistent user experience on any device.
