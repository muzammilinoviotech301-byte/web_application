Key features

Accelerate SAP development with Joule for developers

  • Use AI to generate code and app logic aligned with SAP-centric programming models from natural language descriptions.

  • Create data models and sample data conforming to apps with Joule copilot.

  • Produce rapid unit tests with AI for existing code to increase quality and precision.

Learn more about the AI capabilities 

Tailored for SAP development

  • Extend SAP S/4HANA and other SAP and non-SAP systems rapidly.

  • Utilize prebuilt integrations, APIs, and business services via the service center.

  • Leverage trusted security from SAP BTP for authentication, authorization, and SAP data protection.

Enhanced fusion development

  • Enable fusion team development by sharing application components, such as user experience, business logic, and processes.

  • Give developers the choice of SAP Build low-code, SAP Build Code for Java/JavaScript, and ABAP environment for application and extension development.

  • Drive secure collaboration with unified governance and simplified application lifecycle management for professional and citizen developers.
