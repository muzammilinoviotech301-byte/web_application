Frequently asked questions

SAP Build is a solution that allows users to:

  • Use pro-code tools to develop SAP Cloud Application Programming Model (CAP) applications.

  • Use ABAP Cloud environments to extend core SAP functionalities.

  • Automate business processes and manual tasks with low-code and drag-and-drop simplicity.

  • Design digital workspaces connecting applications for seamless collaboration.

SAP Build is for developers, IT professionals, and business users who want to create and customize business applications. Offering capabilities across low-code, code-first, and generative AI, SAP Build facilitates a myriad of development possibilities across functional areas of an organization, including human resources, procurement, finance, supply chain, and more.

SAP Build supports a flexible, full-stack development approach by providing two programming models:

  • ABAP Cloud: For developing applications and extensions using the ABAP programming language, tightly integrated with the SAP ecosystem.

  • SAP Cloud Application Programming Model (CAP): For development using Java (with Spring Boot) or JavaScript/TypeScript (with Node.js).

This flexibility extends across the full stack, with robust support for:

  • UI frameworks: Seamlessly integrate with popular UI frameworks, including SAPUI5, SAP Fiori elements, and SAP Web Components.

  • Databases: Connect to a variety of databases, such SQLite Service, PostgreSQL, and SAP HANA Cloud.

 

By combining these professional development tools with powerful low-code and generative AI capabilities, SAP Build provides a complete platform for users to create enterprise-grade applications and extensions that solve their unique business challenges.

AI capabilities in SAP Build include

  • AI assistance in pro-code tools  that help developers understand existing code better, as well as generate code, unit tests, data models, and sample data.

  • AI assistance in low-code tools  that allows users to automatically generates UI, formulas, and translations.

  • AI assistance in automation tools  that enable users to generate automation workflows, make informed decisions, and get summarized explanations of various artifacts.

  • AI assistance in business portals that help users with navigation, transactions, content management, and decision-making through natural language interactions, as well as step-by-step guidance and instant answers from business documents.

 

All the design-time capabilities for developers in SAP Build are made available through Joule for developers.

SAP Build includes both low-code and pro-code capabilities ranging from drag-and-drop functionalities to advanced, AI-based code generation. This allows both developers and business experts to build and extend applications and automate processes in ways that work best for their requirements, allowing for greater developer flexibility and customization, tailored to specific business requirements and needs.

 

With SAP Build, customers can enjoy the ease of low-code, along with developer power of pro-code with SAP Build Code and SAP BTP ABAP environment and SAP S/4HANA ABAP Cloud environment.

SAP Build is included as part of SAP Business Suite. The unified SAP Build offering consolidates key capabilities for application development, automation, and low-code UI generation, with a clear strategic direction toward providing access to low-code and code-first development.
