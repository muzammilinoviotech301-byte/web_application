FAQ

Joule Work is an intent-driven workspace that brings together your data, applications, and agent workflows in one place—so teams don’t have to switch between systems or manually coordinate tasks and handoffs. People express what they want to accomplish, and Joule Assistants surface the right insights, automate routine work, and coordinate AI agents so humans can focus on the decisions that move the business forward.

Desktop extends Joule Work’s governed workflow transformation to employees’ desktops, enabling intent-driven work across local files, applications, SAP business systems, and approved third-party tools. It brings SAP business context, pre-built business workflows, and connected systems together in one governed workspace, helping organizations transform fragmented work into governed workflows. It enables employees to access business processes where work happens, automate recurring tasks with reusable skills, and execute workflows with enterprise governance, security, and control built in.

Joule Work desktop is a desktop AI solution for general productivity work (files, research, email, coding, analysis). Joule Work is an embedded, system-connected assistant for SAP business process execution.

Yes, Joule Work desktop is secure. Key security measures include:

  • Encrypted local storage: Conversations are stored on your device in an AES-256 encrypted database, with encryption keys stored in your OS keychain.

  • Sandboxed file access: Joule can only read or write files within your selected working directory.

  • Approval gates: Joule always asks before writing files or running terminal commands.

  • Secure credential storage: OAuth tokens and API keys are stored via OS-level secure storage.

Joule Work desktop can automate these tasks:

  • Running scripts (Python, Node, shell commands) in your working directory.

  • Reading, writing, editing, and organizing local files.

  • Searching your email and summarizing inbox content.

  • Pulling calendar data and surfacing schedule insights.

  • Calling external systems via connectors (APIs, databases, third-party tools).

  • Chaining multi-step workflows using skills.

Connectors in Joule Work desktop are built on the MCP (Model Context Protocol) standard. They let Joule connect to external systems—like Jira, databases, or custom APIs—so it can read data, write data, and trigger actions directly from the chat. Users can add connectors, each of which exposes a set of tools that Joule can use in conversation. Authentication supports no-auth, bearer token, or OAuth 2.0.

You can automate anything that involves combining file work, code execution, and external system calls. Examples include:

  • Pulling data from a connector, processing it with a Python script, and saving a formatted report to your working directory.

  • Searching your inbox for emails on a topic, summarizing them, and drafting a response.

  • Running a multi-step analysis across several local documents and outputting results to a new file.

  • Using a skill to standardize a repeatable workflow like weekly status reports, content briefs, and more.

Once you give Joule Work desktop access to a folder on your machine, it can read, write, edit and search files across that folder. Joule will ask for your approval before making any changes.

Joule Work desktop can work with images and documents up to 10 MB, it can work with any file type that Joule can read or generate, including text files, code, CSVs, JSON, Markdown, Office, and PDF documents. It can also create new files as output from a task.
