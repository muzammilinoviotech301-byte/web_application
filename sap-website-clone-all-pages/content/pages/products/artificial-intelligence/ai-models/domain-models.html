What are SAP Domain Models?

SAP Domain Models are SAP native foundation models trained on SAP code, data, and business processes that assist users with AI when querying data or developing code in SAP applications.

SAP Domain Models:

  • Are trained on SAP code, data models, and business process semantics.

  • Function as the world’s best expert on SAP business processes and code.

  • Power Joule, Joule Studio, AI agents, and SAP solutions with domain-specific expertise.

Key benefits

Get accurate answers from all SAP data

Reduce guesswork with outputs grounded in SAP data and metadata, so recommendations and actions are reliable.

Accelerate delivery and modernization of code

Speed up development, onboarding, and migrations with coding recommendations based on native SAP code and architecture.

Adopt AI with confidence

Natively operate within policy guardrails and SAP-managed governance to support secure, compliant AI—reducing risk as you automate SAP workflows.

Key features

SAP-native training data and continuous training

Models are trained on SAP code, data models, and processes to deliver the best output. Continuous training ensures transparent adoption of new data and future product directions.

Answers grounded in SAP context

Connects to SAP repositories and metadata. Uses SAP Knowledge Graph to ground outputs in relevant artifacts, improving precision for code help and process guidance.

Coding made easy

Developers can create, extend, and migrate code with guidance and support from models trained on SAP-optimized code. Code is optimized for each SAP application and for specific languages, such as ABAP.

FAQ

SAP Domain Models are AI foundation models trained and continuously updated by SAP on its code, data, metadata, documented best practices, and business processes.

General foundation models are trained on public information about SAP technology and cannot reach the depth of knowledge that an SAP-owned and trained model can have on proprietary technology.

Joule uses SAP Domain Models when users ask questions using natural language about data in SAP applications. Joule Studio uses SAP Domain Models to provide code when developers want to create new applications or extend and modernize existing ones within SAP. Initial models provide assistance for ABAP and for SAP Ariba code.

SAP Domain Models ground responses generated by AI with accurate content using SAP Knowledge Graph, live data, and historical code from SAP. They’re continuously updated to keep in line with improvements in SAP applications and changes in data models and code.
