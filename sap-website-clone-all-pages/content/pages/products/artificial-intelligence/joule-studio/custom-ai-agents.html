Grounded in business context

Agents built on SAP Knowledge Graph understand your data, processes, and business relationships.

Plan

Identify the right agent for your business.

  • Map your business processes with SAP Signavio to find where agents deliver the highest impact.

  • Use SAP LeanIX to spot duplications, map integrations, and understand dependencies before you build.

  • Generate a product requirements document with the help of Joule asking clarifying questions to sharpen the scope.

Build

Go from intent to a fully designed agent in minutes.

  • Describe your agent in plain language. Joule Studio handles the spec, the code, and the deployment.

  • Build in your terminal or IDE using the Joule Studio CLI with your own development framework and tools.

  • Give your agent the right tools to get the job done, including MCP servers, documents, workflows, and A2A connections.

Test

Validate agent code and behavior before they touch production.

  • Run automated unit tests, single-turn evaluations, and configurable test suites for agent reliability.

  • Inspect reasoning traces and tool call sequences to see exactly how your agent thinks and acts.

  • Measure response accuracy and iterate until the agent behaves the way you expect.

Deploy

Move agents into production faster with a secure, scalable SAP-managed runtime.

  • Push the agent to production in a single action.

  • SAP-managed runtime handles agent security, monitoring, and compliance so your team can focus on building.

  • Support growing agent workloads across use cases and regions without managing infrastructure.

Govern and observe

Get a trusted portfolio view of all your AI agents.

  • SAP AI Agent Hub is built into Joule Studio and automatically registers every agent as a distinct entity.

  • Post-deployment agent evaluations run on a schedule to detect drift before it becomes a problem.

  • Access controls and policy enforcement at the MCP layer govern every tool your agents call.

Frequently asked questions

You can interact with agents you build in Joule Studio directly through Joule Work. Ask a question or make a request and Joule Work routes it to the right agent automatically. Agents can also reach you proactively by sending notifications through workflow connectors or A2A connections.

The difference is that SAP-delivered Joule Agents and Joule Assistants are already available across SAP applications, including HR, finance, procurement, and supply chain. These agents are ready to deploy with no additional development required.

 

Custom agents are for processes that are unique to your business: your approval workflows, your data structures, and your rules. Joule Studio is where you can build those.

 

If a prebuilt agent covers your use case, start there. If it doesn't, Joule Studio is your path.

Agents you build in Joule Studio are grounded in SAP Knowledge Graph, which means they understand your SAP data relationships, object models, and process structures before you write a single line of code.

 

Joule Studio also gives you the option to extend SAP-delivered agents, providing you with a template to start your AI project.

 

Conversely, most agent builders give you a blank canvas, so you have to replicate all the business context to harness the agent.

You don’t necessarily need to manually write code to build a custom agent. Business users with any level of technical development expertise can use Joule Studio to create a working agent.

 

Business analysts can describe what an agent should do in plain language directly in the Joule Studio web UI. The platform handles the spec, the code, and the deployment.

 

Developers who want full control can build pro-code in Visual Studio Code, Cursor, or Cline using the Joule Studio CLI with any agentic framework. Both paths produce the same deployable artifact.

Joule Studio handles governance for custom agents through SAP AI Agent Hub, which is included with Joule Studio for up to 500 agents. Every agent you deploy is automatically registered, observable, and governed from day one. Agent actions are logged under a distinct agent identity, separate from user actions, so every action is attributable in the audit trail. You can manage SAP-built, custom, and non-SAP agents from a single entry point.

No, Joule Studio doesn’t require SAP LeanIX or SAP Signavio to work—they’re both optional. SAP LeanIX surfaces your business architecture and SAP Signavio provides process conformance data, making your agents significantly more capable. Both are optional amplifiers, not prerequisites.
