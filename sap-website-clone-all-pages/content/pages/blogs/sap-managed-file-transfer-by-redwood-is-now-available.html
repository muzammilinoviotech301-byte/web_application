SAP Managed File Transfer (SAP MFT) by Redwood is now available as an SAP Solution Extension (SOLEX)—co-sold and co-supported by SAP. It is a pleasure to announce this release, the result of close collaboration between SAP and Redwood Software to bring secure, high-performance file transfer into the SAP landscape.

For enterprises that require advanced file transfer needs, the SAP MFT solution secures, automates, and governs file transfers without re-engineering your network. It brings high-performing, enterprise-grade file transfer capabilities into a single, validated, RISE-ready architecture.

What Is SAP MFT?

SAP MFT is an SAP Solution Extension that extends SAP Integration Suite and SAP Cloud ERP with governed, high-volume managed file transfer—completing the file transport layer of the SAP integration architecture. It is procured, contracted, and supported through SAP under a single vendor relationship.

Key MFT Scenarios

Exchange files (or high volume of files) without size limits

With SAP MFT, files are processed at the infrastructure level, separate from the API layer, with no practical upper file-size or file-volume limit. If needed, resume interrupted transfers from the point of failure rather than from zero with checkpoint restart.

Migrate on-premises B2B trading partners to RISE with SAP

For those that use SAP PI/PO for managed file transfer, SAP MFT serves as a validated path for lift-and-shift of SAP PI/PO trading partners, as well as connections from a non-SAP managed file transfer solution, into a RISE environment without manually rebuilding each external connection or relying permanently on workarounds.

Meet network segmentation requirements without exposing internal systems

A reverse-proxy gateway with DMZ streaming keeps internal systems shielded from direct exposure to the internet, without requiring changes to existing firewall policy.

Extend log retention for file transfer activities for compliance and audit

Configurable long-term file logging retention with tamper-evident, chain-of-custody audit trails for every file lifecycle event.

Benefits at a Glance

SAP customers can realize these benefits when leveraging SAP MFT in their complex, high-volume environments:

Enterprise security and compliance with proven file governance

Take advantage of best-in-class security controls, including a zero-trust architecture with a zero-breach history, granular least-privilege permissions, and a secure reverse-proxy architecture that keeps internal systems hidden from external threats. Extensive compliance management extends audit log retention well beyond typical 30-day SAP Integration Suite retention and can be customized to support requirements for SOX, GDPR, PCI-DSS, GLBA, and more. Secure, file-based automation reduces human error risk across every file-based process, with a built-in Key Management System that automates certificate and key expiration tracking to prevent compliance lapses before they happen.

Operational freedom to architect file-based processes

Move files using universal B2B protocols, with instant inbound protocol listeners and a library of 100+ no-code automation templates to help IT operations build workflows more easily. Centralize file transfer operations on a single dashboard that scales with trading partner volume and workload spikes, with no per-connector fees or high-volume penalties that erode ROI. Deploy across any cloud using SAP MFT as an integration bridge that connects multi-vendor cloud and on-premises environments without custom workarounds.

Enterprise-scale file performance for high-volume orchestration

Migrate MFT processes from SAP PI/PO or other legacy MFT platforms to RISE with SAP through a standard, proven path that protects your transformation timeline. Process files of any size or any volume—including multi-gigabyte or terabyte-sized datasets—at the infrastructure level, separate from the API layer, so large files never put your system uptime at risk. Protect your RISE architecture with an SAP-validated, upgrade-safe solution that replaces fragile custom scripting and keeps file transfer processes intact through every SAP update.

Getting Started

By extending SAP Integration Suite, it delivers a secure solution for customers looking to modernize B2B file transfer processes, transition to RISE with SAP, or replace legacy platforms like SAP PI/PO.
