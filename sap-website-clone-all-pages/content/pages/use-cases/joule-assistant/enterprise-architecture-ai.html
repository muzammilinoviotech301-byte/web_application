Overview

The Enterprise Architecture Assistant helps enterprise architects complete work faster, ensure better-quality and more up-to-date data in their inventory, and avoid switching between applications when seeking answers to questions. Instead of manually searching internal documents or internet resources for information to enrich data on inventory factsheets, architects can use agents directly in SAP LeanIX to perform such tasks.

Tasks this assistant can help with:
  • Accurately completing data input and factsheets
  • Simplifying research and information-gathering
  • Accelerating work and reducing manual effort for enterprise architects
Example use cases for this assistant:
  • Curation of data across factsheets in the inventory
  • Investigation into multiple sources simultaneously
  • Construction of transformation plans with complete, up-to-date information
