Overview

The Onboarding Assistant streamlines the new hire experience with guided task management, prioritization, and customization. It intelligently orchestrates task completion and delivers personalized experiences at scale to help ensure employees are successful from the start.

Tasks this assistant can help with:
  • Creating and tracking onboarding tasks
  • Providing intelligent prioritization
  • Converting and localizing custom forms
Example use cases for this assistant:
  • Onboarding process automation
  • Personalizing day-one experiences
  • Prioritizing new-hire tasks

Benefits

Faster onboarding
Use agents to coordinate onboarding tasks automatically, helping ensure accurate and on-time completion.

Increased new hire satisfaction
Provide a personalized onboarding experience that helps new hires feel engaged and ready for day one.

Shorter time to productivity
Empower employees and strengthen compliance with the tasks and guidance they need for a successful start.

Agents used by this assistant

Use the Onboarding Assistant to orchestrate specialized AI agents, including Joule Agents that apply SAP’s process expertise.

Agent

Description

Onboarding Task Management Agent

Intelligently coordinates and tracks onboarding actions for managers, HR, and new hires.

Onboarding Task Creation Agent

Creates one-off onboarding tasks in real time to keep processes on track.

Onboarding Custom Form Agent

Converts, generates, and deploys compliance documents into ready-to-use, multi-language onboarding forms.
