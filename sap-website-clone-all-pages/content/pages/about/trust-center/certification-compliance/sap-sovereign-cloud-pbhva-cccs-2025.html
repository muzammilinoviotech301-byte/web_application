SAP Sovereign Cloud Canada Canadian Centre for Cyber Security (CCCS) PBHVA Cloud Assessment Summary 2025

The Government of Canada Cloud Service Provider Security Assessment Process provides a means for cloud service providers to undergo standardized assessments that inform risk owners responsible for Security Assessment and Authorization.

 

SAP Sovereign Cloud Canada has been assessed against the Government of Canada IT security requirements Protected B High Value Assets (PBHVA) data categorization of information and services. The assessment was completed July 2025.
